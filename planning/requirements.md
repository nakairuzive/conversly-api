# Requirements Document

### Purpose
The purpose of this api is to help people start meaningful conversations and build connections

### Target Users
- Introverts
- Students 
- Professionals
- People on dates
- Networking events
- Friends
- Families

### Functional Requirements 

The API should 
- Return conversation starters 
- Filter by relationship
- Filter by familiarity
- Filter by setting
- Return random questions
- Search questions
- Return categories
- Allow adding new questions (*future)

### Non-functional Requirements

- Fast
- Easy to use
- RESTful
- Well documented
- JSON responses only
