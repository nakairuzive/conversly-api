# Data Design

Each conversation starter needs: id, question, relationship, familiarity, setting, tone, tags

| Field Name     | Data Type        | Required | Description                        | Example                                           |
| -------------- | ---------------- | -------- | ---------------------------------- | ------------------------------------------------- |
| `_id`          | ObjectId         | Yes      | Automatically generated by MongoDB | `68b2...`                                         |
| `question`     | String           | Yes      | The conversation starter           | "What's something you've always wanted to learn?" |
| `relationship` | String           | Yes      | Who the user is talking to         | `"friend"`                                        |
| `familiarity`  | String           | Yes      | How well they know the person      | `"close"`                                         |
| `setting`      | String           | Yes      | Where the conversation takes place | `"coffee"`                                        |
| `tone`         | String           | Yes      | Mood or style of the question      | `"casual"`                                        |
| `tags`         | Array of Strings | No       | Topics related to the question     | `["travel", "food"]`                              |
| `createdAt`    | Date             | Yes      | When the document was created      | `2026-07-27T15:00:00Z`                            |
| `updatedAt`    | Date             | Yes      | Last modified date                 | `2026-07-27T15:00:00Z`                            |
